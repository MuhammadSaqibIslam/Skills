============================================================
Web Application (Copy)
============================================================

Platform: web
Description: Comprehensive design guidelines for responsive web applications. Covers responsive breakpoints, navigation patterns, grid systems, accessibility standards, and cross-browser considerations.

────────────────────────────────────────────────────────────
1. Responsive Design
────────────────────────────────────────────────────────────
   Priority: must | Effort: m | Category: app-size

   App must be fully responsive across all viewport sizes: mobile (320px+), tablet (768px+), desktop (1024px+), wide (1440px+). Use CSS media queries or container queries. Mobile-first approach recommended.

   Acceptance Criteria:
   • App must be fully responsive across all viewport sizes: mobile (320px+), tablet (768px+), desktop (1024px+), wide (1440px+)
   • Use CSS media queries or container queries
   • Mobile-first approach recommended

   User Story: As a user on any device, I want to see responsive design applied in the interface, so that the interface adapts properly to my screen size

────────────────────────────────────────────────────────────
2. Maximum Content Width
────────────────────────────────────────────────────────────
   Priority: must | Effort: xs | Category: app-size

   Maximum content width: 1200-1440px, centered on larger screens with auto margins. Prevents content from stretching on ultra-wide monitors. Background can extend full width.

   Acceptance Criteria:
   • Maximum content width: 1200-1440px, centered on larger screens with auto margins
   • Prevents content from stretching on ultra-wide monitors
   • Background can extend full width

   User Story: As a user, I want to see maximum content width applied in the interface, so that the application follows platform design guidelines consistently

3. Minimum Supported Width
────────────────────────────────────────────────────────────
   Priority: must | Effort: m | Category: app-size

   Minimum supported viewport width: 320px (iPhone SE). All content must be accessible at 320px. No horizontal scrolling at any supported viewport.

   Acceptance Criteria:
   • Minimum supported viewport width: 320px (iPhone SE)
   • All content must be accessible at 320px

────────────────────────────────────────────────────────────
   Priority: must | Effort: m | Category: app-size

   Acceptance Criteria:

6. Header Content
────────────────────────────────────────────────────────────
