============================================================
macOS Desktop Application (Copy)
============================================================

Platform: macos
Description: Comprehensive design guidelines for native macOS desktop applications. Covers window sizing, native chrome, sidebar navigation, spacing, and Apple Human Interface Guidelines alignment.

────────────────────────────────────────────────────────────
1. Default Window Size
────────────────────────────────────────────────────────────
   Priority: must | Effort: xs | Category: app-size

   1200 x 750 px as the default initial window size. Standard comfortable size for most macOS displays. Provides enough room for sidebar + content without feeling cramped.

   Acceptance Criteria:
   • 1200 x 750 px as the default initial window size
   • Standard comfortable size for most macOS displays
   • Provides enough room for sidebar + content without feeling cramped

   User Story: As a user, I want to see default window size applied in the interface, so that the application follows platform design guidelines consistently

────────────────────────────────────────────────────────────
2. Fixed Window Dimensions
────────────────────────────────────────────────────────────
   Priority: must | Effort: xs | Category: app-size

   Window size is fixed and non-resizable unless explicitly required by the app. Keeps the layout predictable. If resizing is needed, define minimum (800x500) and maximum bounds.

   Acceptance Criteria:
   • Window size is fixed and non-resizable unless explicitly required by the app
   • Keeps the layout predictable
   • If resizing is needed, define minimum (800x500) and maximum bounds

   User Story: As a user, I want to see fixed window dimensions applied in the interface, so that the application follows platform design guidelines consistently

────────────────────────────────────────────────────────────
3. Retina Display Support
────────────────────────────────────────────────────────────
   Priority: must | Effort: m | Category: app-size

   All assets and layouts must render crisply on Retina (2x) displays. Use vector assets (SVG/SF Symbols) wherever possible. Avoid raster images below 2x resolution.

   Acceptance Criteria:
   • All assets and layouts must render crisply on Retina (2x) displays
   • Use vector assets (SVG/SF Symbols) wherever possible
   • Avoid raster images below 2x resolution

   User Story: As a user, I want to see retina display support applied in the interface, so that the application follows platform design guidelines consistently

────────────────────────────────────────────────────────────
4. Full-Screen Mode
────────────────────────────────────────────────────────────
   Priority: could | Effort: m | Category: app-size

   Support native macOS full-screen mode if the app has content-heavy views. Use NSWindow full-screen APIs. Ensure layout adapts gracefully to the larger canvas.

   Acceptance Criteria:
   • Support native macOS full-screen mode if the app has content-heavy views
   • Use NSWindow full-screen APIs
   • Ensure layout adapts gracefully to the larger canvas

   User Story: As a user, I want to see full-screen mode applied in the interface, so that the application follows platform design guidelines consistently

────────────────────────────────────────────────────────────
5. Top Bar Height
────────────────────────────────────────────────────────────
   Priority: must | Effort: xs | Category: top-bar

   Top bar (title bar area) height: 32px. Matches native macOS title bar height. Do not exceed this to maintain platform consistency.

   Acceptance Criteria:
   • Top bar (title bar area) height: 32px
   • Matches native macOS title bar height
   • Do not exceed this to maintain platform consistency

   User Story: As a user, I want to see top bar height applied in the interface, so that the application follows platform design guidelines consistently

────────────────────────────────────────────────────────────
6. Traffic Lights Placement
────────────────────────────────────────────────────────────
   Priority: must | Effort: l | Category: top-bar

   Left side: standard macOS traffic light buttons (close, minimize, zoom) at their default position. Do not reposition or restyle the traffic lights. Use default system spacing (left: 7px, vertical center of title bar).

   Acceptance Criteria:
   • Left side: standard macOS traffic light buttons (close, minimize, zoom) at their default position
   • Do not reposition or restyle the traffic lights

7. Custom Window Title
────────────────────────────────────────────────────────────
   Priority: should | Effort: l | Category: top-bar

   Center or left-aligned custom title text in the title bar area. Use the app name or current context. Keep it concise (under 30 characters). Font should be system default or match heading style.

   Acceptance Criteria:
   • Center or left-aligned custom title text in the title bar area

────────────────────────────────────────────────────────────
   Priority: should | Effort: s | Category: top-bar

────────────────────────────────────────────────────────────

   Acceptance Criteria:
   • Use a left sidebar for primary navigation

────────────────────────────────────────────────────────────

22. 8pt Grid System
────────────────────────────────────────────────────────────
   Priority: must | Effort: l | Category: spacing

   Use an 8-point grid system for all spacing, sizing, and alignment. All margins, paddings, and gaps should be multiples of 8 (8, 16, 24, 32, 40, 48). Use 4px for minor adjustments only.

   Acceptance Criteria:
   • Use an 8-point grid system for all spacing, sizing, and alignment
   • All margins, paddings, and gaps should be multiples of 8 (8, 16, 24, 32, 40, 48)
   • Use 4px for minor adjustments only

   User Story: As a user, I want to see 8pt grid system applied in the interface, so that the layout feels balanced and well-organized
