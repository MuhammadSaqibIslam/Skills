============================================================
iPad / Tablet Application (Copy)
============================================================

Platform: tablet
Description: Comprehensive design guidelines for iPad and tablet applications. Covers split views, multitasking, pointer support, adaptive layouts, and tablet-specific interaction patterns.

────────────────────────────────────────────────────────────
1. Full Screen Layout
────────────────────────────────────────────────────────────
   Priority: must | Effort: m | Category: app-size

   Design for iPad base resolution: 1024 x 1366 pt (12.9" iPad Pro) and 820 x 1180 pt (10.9" iPad). Use adaptive layout that works across all iPad sizes. Design at logical points, not pixels.

   Acceptance Criteria:
   • Design for iPad base resolution: 1024 x 1366 pt (12
   • 9" iPad Pro) and 820 x 1180 pt (10
   • Use adaptive layout that works across all iPad sizes
   • Design at logical points, not pixels

   User Story: As a user on any device, I want to see full screen layout applied in the interface, so that the interface adapts properly to my screen size

────────────────────────────────────────────────────────────
2. Multitasking Window Sizes
────────────────────────────────────────────────────────────
   Priority: must | Effort: m | Category: app-size

   Support all iPad multitasking modes: full screen, split view (1/3, 1/2, 2/3), and slide over (320pt wide). App may run at any width from 320pt (slide over) to full screen. Layout must adapt to all sizes.

   Acceptance Criteria:
   • Support all iPad multitasking modes: full screen, split view (1/3, 1/2, 2/3), and slide over (320pt wide)
   • App may run at any width from 320pt (slide over) to full screen
   • Layout must adapt to all sizes

   User Story: As a user, I want to see multitasking window sizes applied in the interface, so that the application follows platform design guidelines consistently

────────────────────────────────────────────────────────────
3. Orientation Support
────────────────────────────────────────────────────────────
   Priority: must | Effort: m | Category: app-size

   Support both portrait and landscape orientations. Layout adapts between the two. iPad users rotate freely. Both orientations must be fully functional and well-designed.

   Acceptance Criteria:

   • Layout adapts between the two

   • Both orientations must be fully functional and well-designed

────────────────────────────────────────────────────────────
   Priority: should | Effort: m | Category: app-size

   Acceptance Criteria:

6. Navigation Bar
────────────────────────────────────────────────────────────

   Acceptance Criteria:
