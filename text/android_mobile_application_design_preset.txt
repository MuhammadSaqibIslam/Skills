============================================================
Android Mobile Application (Copy)
============================================================

Platform: android
Description: Comprehensive design guidelines for Android phone applications following Material Design 3 (Material You) principles. Covers system bars, navigation patterns, touch targets, and Android-native patterns.

────────────────────────────────────────────────────────────
1. Full Screen Layout
────────────────────────────────────────────────────────────
   Priority: must | Effort: s | Category: app-size

   App occupies the full screen. Design for base density: 360 x 800 dp (common Android phone). Use dp (density-independent pixels). Designs adapt across screen densities (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi).

   Acceptance Criteria:
   • App occupies the full screen
   • Design for base density: 360 x 800 dp (common Android phone)
   • Use dp (density-independent pixels)
   • Designs adapt across screen densities (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi)

   User Story: As a user, I want to see full screen layout applied in the interface, so that the application follows platform design guidelines consistently

────────────────────────────────────────────────────────────
2. Edge-to-Edge Display
────────────────────────────────────────────────────────────
   Priority: must | Effort: l | Category: app-size

   App content extends behind system bars (status bar and navigation bar) with proper insets. Use WindowInsetsCompat for proper inset handling. Content scrolls behind transparent system bars.

   Acceptance Criteria:
   • App content extends behind system bars (status bar and navigation bar) with proper insets
   • Use WindowInsetsCompat for proper inset handling
   • Content scrolls behind transparent system bars

   User Story: As a user, I want to navigate using edge-to-edge display, so that I can find and access features intuitively

────────────────────────────────────────────────────────────
   Priority: must | Effort: m | Category: app-size

   Support screen widths from 320dp (small) to 480dp (large phones). Test at multiple sizes. Android has massive device variety. Use ConstraintLayout and flexible components. Test on small and large devices.

   Acceptance Criteria:
   • Support screen widths from 320dp (small) to 480dp (large phones)
